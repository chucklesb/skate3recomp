## Notable Changes

### Game and application
- **Less visible tiling on canal water.** The canals' ripple texture used to
  repeat every metre in a visible grid. A rotated second copy of the ripples
  is now blended in and varied across the canal, which breaks up the grid.
  It's on by default; set `skate3_native_render_scene_water_detile` to 0 to
  get the game's original look.

### Fixes
- **Canal water reflected orange-brown (KI-122).** In the native renderer,
  the canals reflected an orange-brown colour where the game shows blue sky.
  How much depended on the viewing angle: looking along the surface, it
  covered most of the canal. Fixed: the reflection is blue again.
- **Canal water had no shadows and looked flat (KI-122).** The canals were a
  bright, even blue with no shadows from bridges or the skater. The game
  draws them as murky water with blue glints, darker in shade. They now use
  a port of the game's own water shader and match the original closely.

### Scenario harness and tooling
- **Teleport to coordinates:** `teleport pos = [x, y, z]` with an optional
  `yaw`. For a far target, it first hops to the nearest named spot, so the
  area can load before the final move.
- **Canal water debug view:** `skate3_native_render_scene_water_debug` shows
  one part of the water shading at a time (`scenarios/water_debug.toml`).
- **Vulkan shader generator:** `tools/generate_native_spirv.py` rebuilds the
  native renderer's precompiled Vulkan shaders. Shader changes can now reach
  Vulkan and the Odin 2, not just D3D12.
