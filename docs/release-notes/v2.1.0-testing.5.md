## Notable Changes

### Fixes
- **Replays ran far slower than live skating (KI-123).** Watching or editing
  a replay from the pause menu or My Replays could drop into the teens at a
  30 fps cap, with bad frame pacing and the skater's physics going wrong.
  The replay editor had been holding the game's own (emulated) renderer on
  for a skater view that is never shown, on top of the native renderer.
  That is fixed, and the replay's per-frame hidden skater passes (six
  meshes into a small texture nothing displays) are now skipped as well.
  On the Odin 2, uncapped replays went from about 54 / 48 / 51 fps to
  60 / 52 / 56 fps, and the worst frames dropped from 44–71 ms to 32–40 ms.
  The skip can be turned off with
  `skate3_native_render_scene_replay_aux_skip=false`.
- **Saved reels get a correct thumbnail.** With the fix above, a reel's
  automatic thumbnail was black, or showed an image from another replay. It
  is now taken from the native renderer's frame at the moment you save
  (`skate3_native_render_scene_reel_thumb_native`, on by default).

### Scenario harness and tooling
- **`play_reel` waits for free skate to settle** before it finishes: 30
  frames back in free skate with no loading screen. Back-to-back reels no
  longer start while the previous reel's restream is still loading, which
  could crash the game.
- **`play_reel stills_capture = true`** takes a RenderDoc frame at each
  still (`scenarios/reel_capture.toml`).
- **Performance segments:** `perf_report.py` splits a run by `mark perf
  <name>` … `mark perf end` marks; `scenarios/perf_ki123.toml` compares
  live skating against three reels, uncapped.
- **New helpers** in `tools/harness/`: `live_cvar_ab.sh` (flip a setting
  back and forth in a live session and sample fps) and `reel_thumbs.py`
  (extract saved reels' thumbnails and flag duplicates).
- **Reel slot files above 9** (named in hex, e.g. `A.B`) are now read
  correctly by `reels` and `play_reel`; `reels` also lists clips in the
  game's order.

### Documentation
- KI-123 in `docs/known-issues.md` has the cause, the fixes and what is
  still open (the thumbnail write takes about 120 ms when a reel is saved).
- `docs/open-work.md` gains a UI and overlays section (performance HUD and
  indicator layout, MangoHud, the recomp settings menu) and an
  investigation into where else the emulated renderer still runs.
