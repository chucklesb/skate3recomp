## Notable Changes

Everything since v2.1.0-aarch64.3.

### Fixes
- **The skater's forearm froze, vanished and floated off the arm (KI-117).**
  Most visible in skate reel replays: when the skater crouched with the
  hands down near the knees, a forearm stayed frozen for a moment, then
  disappeared, then came back floating off the arm. The renderer was
  rejecting the game's own pose for the folded arm as implausibly small. It
  now accepts it, and the arm stays on the body (on the Odin 2 and on PC, in
  the reel that showed it at three moments).
  - Setting: `skate3_native_render_scene_char_spread_floor` (0.1; 0.2 brings
    back the old behaviour).
  - Two further safety nets, ported from dougieprishpreed/skate3recomp-plus,
    are included but **off by default**, for comparison only:
    `skate3_native_render_scene_rescue_serve` and
    `skate3_native_render_scene_smooth_continuity`.

### Scenario harness and tooling
- **Body-piece sync check:** `skate3_native_render_scene_char_sync` makes
  the renderer log, each frame, any piece of a character that isn't drawn
  from the same moment as the rest of the body, or that disappears, and why.
  `tools/harness/char_sync_report.py` summarises a run, compares runs, and
  can fail a run (`--max-bad`).
- **`scenarios/repro_reel_forearm.toml`:** plays a recorded reel from its
  first marker with the check on. The harness now logs every marker of a
  reel, not just the first.
- **Native-only audit:** the emulated-pass census records which "windows"
  let the game's own renderer run, and `census_report.py --audit-only` gives
  a verdict per screen. `tools/harness/gen_native_tour.py` writes a tour
  scenario that visits every screen where it may still run.

### Documentation
- `docs/native-only.md`: the phase 0 baseline. Every screen measured on
  Windows, plus photo challenges on the Odin 2, where the game's own renderer
  still draws the most (72-96 draws a frame for an offscreen skater pass).
- `docs/known-issues.md`: the KI-117 follow-up, with the cause and the
  measurements.
