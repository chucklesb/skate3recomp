## Notable Changes

### Game and app
- **Lens effect setting:** `skate3_native_render_scene_screen_fx` (on by
  default) controls the camera's fisheye and vignette, seen mainly in skate
  reel replays. Off gives a plain picture on both the native and the
  emulated renderer.

### Scenario harness and tooling
- **Reel playback looks like the game's:** `play_reel` now shows the game's
  own loading screen while a reel loads and on the way back to free skate,
  instead of the world visibly streaming in. The editor's view of the reel's
  last frame no longer flashes before playback; the screen stays black until
  the first played frame.
- **No lens in reel stills by default:** `play_reel` turns the fisheye and
  vignette off for the reel, so stills show the plain scene; `lens = true`
  keeps them. With `every_frames`, the load is screenshotted too
  (`<tag>_load`). New scenario: `scenarios/reel_lens.toml`.
- **Faster device runs:** the Odin 2 runner only rebuilds when build inputs
  changed and only redeploys when the device has a different build. A rerun
  with no changes took 157 s instead of 426 s.
- **Device files without a session:** `pull` and `reels` read files from the
  Odin 2's guest system (settings, logs, saved reels) in about a second,
  without starting DroidDeck. `reels --install-windows` copies the device's
  reels into the Windows test profile.
- **Start-spot fix:** scenarios with a `start_spot` in another district
  failed on the Odin 2 because the teleport was sent on the first gameplay
  frame. It now waits 90 frames first.
- **Helper tools** in `tools/harness/`: `shots.py` (contact sheets, crops,
  brightness statistics), `video_frames.py` (screen-recording frames),
  `ropa_shadow_trace.py`.
